# Visual assets

- `geoscope_overview.svg` is the public-facing final-method architecture.
- `method_lineage.svg` preserves the complete experiment journey and shows how
  M3-B and Method 2 converge in GeoSCOPE.
- `qualitative/geoscope_scene2.gif` and `geoscope_scene6.gif` are frozen,
  prediction-only reconstruction examples generated by the deterministic
  release script.

No asset contains Endoscope1 ground truth. Do not add target images without
explicit redistribution permission. Generation details and manifests are in
[`qualitative/README.md`](qualitative/README.md).
